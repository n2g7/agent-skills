## Marketing adjectives and boosters (ban)

Do not use: seamless, seamlessly, robust, powerful, cutting-edge, effortless, effortlessly, world-class, next-generation, revolutionary, blazing, lightning-fast, elegant, delightful, turnkey, best-in-class, state-of-the-art, game-changing, first-class, battle-tested, enterprise-grade, supercharge, unlock, unleash, empower, empowers, industry-leading, innovative (as filler), holistic, comprehensive (as filler).

Replace with a concrete claim, or delete the word.

## Stacked filler

| Avoid | Prefer |
|-------|--------|

| please be aware that | (delete) |
| in order to be able to | to |
| this may help to improve | this improves |
| serves as a means to | (use a plain verb) |
| is designed to allow | lets / allows |

## One name per thing

Pick one term and keep it. Examples:

| Do not mix | Pick one |
|------------|----------|
| service / component / module (same unit) | one name for that unit |
| user / customer / client (same person) | one name for that person |
| error / failure / issue / problem (same event) | one name for that event |
