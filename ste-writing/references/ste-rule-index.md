# ASD-STE100 Issue 9 — Part 1 rule map

Source: ASD-STE100 Simplified Technical English, Issue 9 (2025-01-15). This file lists rule numbers and agent actions only. It does not reproduce the Part 2 dictionary.

Use this when you need the official section structure. For everyday rewrites, follow [SKILL.md](../SKILL.md).

## Section 1 — Words

| Rule | Title (summary) | Agent action |
|------|-----------------|--------------|
| 1.1 | Use approved / allowed word types | Prefer short approved common words; allow technical nouns |
| 1.2 | Approved word = approved part of speech | Do not use a noun as a verb or reverse |
| 1.3 | One approved meaning per word | Do not stretch meanings (e.g. "fall" = move down) |
| 1.4 | Approved verb and adjective forms only | Stick to simple, dictionary-allowed forms |
| 1.5–1.6 | Technical nouns | Allow field nouns; keep them short and clear |
| 1.7 | Technical nouns are not verbs | Reword ("do a filter" → "filter") |
| 1.8–1.10 | Company / industry nouns; no slang | One standard term; no jargon as nouns |
| 1.11 | One name per item | Never rename the same thing mid-text |
| 1.12–1.13 | Technical verbs | Allow field verbs; do not nominalize them |
| 1.14 | American English spelling | Use American spelling unless directed otherwise |

## Section 2 — Multi-word nouns

| Rule | Title (summary) | Agent action |
|------|-----------------|--------------|
| 2.1 | Max three words in a multi-word noun | Prefer short noun phrases |
| 2.2 | Longer technical names | Write the full name first; then use a short form if defined |

## Section 3 — Verbs

| Rule | Title (summary) | Agent action |
|------|-----------------|--------------|
| 3.1–3.2 | Allowed verb forms and tenses | Prefer imperative, simple present/past/future |
| 3.3 | Past participle as adjective | "the closed valve", not complex passives |
| 3.4 | No complex auxiliary stacks | Split or simplify the verb phrase |
| 3.5 | Limit "-ing" forms | No "-ing" as main verb when a simple tense works |
| 3.6 | Active voice | Prefer active; passive only when actor is unknown or irrelevant (descriptive) |
| 3.7 | Verb for the action | "analyze", not "perform an analysis" |

## Section 4 — Sentences

| Rule | Title (summary) | Agent action |
|------|-----------------|--------------|
| 4.1 | Short, clear sentences | Split long sentences |
| 4.2 | No omitted words or contractions | Expand contractions; keep articles |
| 4.3 | Vertical lists for complex text | One idea per list item |
| 4.4 | Connecting words between related sentences | Use plain connectors when needed |
| 4.5 | Articles and demonstratives | Use a, an, the, this, these when applicable |

## Section 5 — Procedural writing (strict)

| Rule | Title (summary) | Agent action |
|------|-----------------|--------------|
| 5.1 | Max 20 words per sentence | Enforce 20-word cap |
| 5.2 | One instruction per sentence | Split combined commands |
| 5.3 | Imperative form | "Open the valve." |
| 5.4 | Condition before command | "If X, do Y." |
| 5.5 | Notes give information only | Never put commands in notes |

## Section 6 — Descriptive writing

| Rule | Title (summary) | Agent action |
|------|-----------------|--------------|
| 6.1 | Give information gradually | Order from known to new |
| 6.2 | Key words and phrases for structure | Keep topic signals consistent |
| 6.3 | Max 25 words per sentence | Enforce 25-word cap |
| 6.4–6.5 | Paragraphs; one topic each | Split mixed topics |
| 6.6 | Max six sentences per paragraph | Split long paragraphs |

## Section 7 — Safety instructions (strict)

| Rule | Title (summary) | Agent action |
|------|-----------------|--------------|
| 7.1 | Label the risk level | Start with Warning / Caution as applicable |
| 7.2 | Clear command or condition first | Lead with the action or condition |
| 7.3 | Explain the risk or result | State what can happen |

## Section 8 — Punctuation and word count

| Rule | Title (summary) | Agent action |
|------|-----------------|--------------|
| 8.1 | No semicolon | Use a period; write two sentences |
| 8.2 | Hyphens for related words | Use hyphens, not dashes, for compounds |
| 8.3–8.5 | Parentheses and list colons | Keep parentheses short; count per STE rules when strict |
| 8.6–8.7 | Word-count units | Abbreviations, hyphenated words count as one word when strict |

**House rule (this skill):** also ban em dashes.

## Section 9 — Writing practices

| Rule | Title (summary) | Agent action |
|------|-----------------|--------------|
| 9.1 | Rebuild the sentence if a word-for-word swap fails | Prefer structural rewrite over awkward synonyms |
| 9.2 | Use each approved word correctly | Match meaning and part of speech |
| 9.3 | Do not make phrasal verbs from two words | Prefer a single plain verb ("start", not "spin up") |
| 9.4 | Consistent terminology and style | Same name, same tone throughout |

## Mode mapping

- **strict** → Sections 1–9, with 5 and 7 fully enforced; sentence caps 20 / 25.
- **STE-flavored** → Emphasize 1.11, 3.4–3.7, 4.x, 6.x, 8.1, 9.3–9.4; relax dictionary lockdown (1.1–1.4).
